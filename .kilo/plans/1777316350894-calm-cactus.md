### 2. CSV Export - Undefined Fields (export-router.ts)
**File:** `app/api/export-router.ts`
**Issue:** CSV export contained "undefined" values for empty fields
**Fix:** Added `safeValue()` helper function to handle null/undefined values properly:
```typescript
function safeValue(value: any, defaultValue = ""): string {
  if (value === null || value === undefined) return defaultValue;
  if (typeof value === "object") return JSON.stringify(value);
  return String(value);
}
```

## Known Limitations

1. **Firestore vs Drizzle ORM:** Schema is defined for MySQL but Firestore is used. This works but limits relational queries.

2. **Role-Based Isolation:** Users can currently see all corps members. For full security, implement row-level filtering by batch/platoon.

3. **No Database Migrations:** Firestore is schemaless. Adding migrations would be needed for PostgreSQL.

4. **No Rate Limiting:** API is open to abuse. Recommend adding rate limiting in production.

## Performance Considerations

- Firestore queries are indexed by default
- Large datasets (>10k records) may need pagination
- Consider virtual scrolling for member lists
- Cache statistics queries with React Query

## Security Considerations

- Firebase Auth handles password hashing
- All writes go through tRPC with auth checks
- Consider adding CSRF protection
- Add input sanitization for user-generated content
- Implement session timeout (30 min recommended)
